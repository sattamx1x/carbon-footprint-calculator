# Carbon Footprint Calculator

A responsive educational carbon footprint calculator built with HTML, CSS, Bootstrap 5, and JavaScript.

## Features
- Climate change introduction and sustainability illustration
- Green navigation tabs for General, Home, Travel, Food, Electronic usage, Shopping, and Result
- Interactive multi-step calculator with a yearly carbon-footprint estimate
- Responsive Bootstrap grid, form controls, and buttons

## Run locally
Open `index.html` in a browser with internet access for the Bootstrap CDN.

## GitHub Pages
In repository **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, and save. The website URL will be `https://sattamx1x.github.io/carbon-footprint-calculator/` after deployment.

## Note
Emission factors are simplified estimates for educational purposes only, not a verified carbon audit.
